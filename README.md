# ⚡ Voltix

Voltix یک آزمایشگاه و دستیار آموزشی فارسی برای هنرجویان الکترونیک هنرستان است.

## امکانات

- ماشین‌حساب قانون اهم
- کد رنگی مقاومت‌های ۴ و ۵ نواری
- تقسیم ولتاژ
- مقاومت LED
- خازن سری/موازی، بار و انرژی
- فیلتر RC
- مرجع ترانزیستورها، آی‌سی‌ها، دیودها، مقاومت‌ها و خازن‌ها
- جست‌وجوی قطعات
- آموزش تعاملی سری/موازی، AC/DC، ترانزیستور، دیود و قانون اهم
- دستیار هوشمند Gemini
- RAG با PDF، chunking، embedding و FAISS
- ارجاع پاسخ‌ها به شماره صفحه PDF
- fallback به پاسخ عمومی
- تبدیل واحد
- جدول کد رنگی مقاومت
- مبدل کد سه‌رقمی خازن
- خروجی HTML معرفی قابل دانلود
- رابط RTL و مناسب موبایل

## نکته مهم درباره هوش مصنوعی رایگان

Voltix از Google Gemini استفاده می‌کند. استفاده از API به کلید Gemini نیاز دارد و سهمیه رایگان/محدودیت آن به حساب و سیاست فعلی Google بستگی دارد. کلید داخل کد قرار نگرفته است.

برای RAG:
1. کلید Gemini را در پنل دستیار وارد کنید.
2. PDF کتاب را بارگذاری کنید.
3. روی «ساخت/بازسازی پایگاه دانش» بزنید.
4. سؤال بپرسید.

## اجرای محلی

Python 3.10 یا بالاتر:

```bash
pip install -r requirements.txt
streamlit run app.py
```

سپس مرورگر را باز کنید.

## Streamlit Cloud

1. یک Repository عمومی یا خصوصی در GitHub بسازید.
2. `app.py` و `requirements.txt` را در ریشه Repository قرار دهید.
3. وارد Streamlit Community Cloud شوید.
4. Repository را انتخاب کنید.
5. فایل اصلی را `app.py` انتخاب کنید.
6. Deploy را بزنید.

هیچ دیتابیس خارجی لازم نیست.

## امنیت

- کلید Gemini را در GitHub یا داخل `app.py` قرار ندهید.
- برای پروژه عمومی، از Secrets سرویس استقرار یا ورود دستی کلید استفاده کنید.
- PDFهای آپلودشده در این نسخه داخل session همان اجرای برنامه پردازش می‌شوند و دیتابیس خارجی ندارند.

## محدودیت RAG

در نسخه ساده و رایگان، index در session ساخته می‌شود. اگر برنامه restart شود، index از بین می‌رود و باید دوباره PDF را بارگذاری و index را بسازید. این تصمیم باعث می‌شود نیاز به دیتابیس خارجی حذف شود.

## HTML

از نوار کناری می‌توانید یک فایل `voltix.html` دانلود کنید. این فایل صفحه معرفی مستقل Voltix است. برای اجرای کامل ماشین‌حساب‌ها و RAG، نسخه Streamlit یعنی `app.py` را اجرا کنید.
